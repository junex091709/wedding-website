# Olivia & Alexander — Wedding Invitation Website

A responsive static wedding invitation website starter with:
- Responsive navigation
- Countdown to December 12, 2026 (Philippine time)
- Story, event details, entourage, dress code and gallery sections
- Google Maps search links for the sample venues
- RSVP modal with browser-local demo storage

## Run locally
Open `index.html` in a browser. No build step is required.

## Before publishing
1. Replace fictional names, venue, date, RSVP deadline and all sample text.
2. Replace gradient photo placeholders with the couple's approved photos.
3. Confirm ceremony and reception map links.
4. Connect RSVP to a real backend or form service. The current demo saves responses only in the visitor's browser and does not send them to the couple.
5. Host the folder on a static host such as GitHub Pages, Netlify or Vercel.
